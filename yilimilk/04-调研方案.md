## 1. 总览

- **这份方案做什么**：把阶段2拆解前还缺的两类关键输入，转化为一份可直接拿去客户现场执行的调研方案——① 五大指标（四个提高、一个降低）的量化基线值；② 当前人工 Excel 推式分货的真实业务流程与规则。
- **为什么现在做调研**：目前企业画像和价值框架已有相当认知，但存在三块硬缺口：痛点只有方向、没有数字（P0 无法实证）；决策链角色是推断；分货补货的实际流程和规则没有客户侧一手还原。这三块不补，阶段2的"业务流程 → 任务"拆解就只能是纸上推断，阶段3的 WSJF 排序也缺数据依据。
- **调研完成后能解锁什么**：
    1. 把 P0 痛点从"推断"升级为"客户数据实证"；
    2. 拿到真实 As-Is 流程，支撑聚焦价值段的逐层拆解；
    3. 摸清系统接口现状，判断方案是"能力移植"还是"部分新建"。
- **需要 FDE 注意**：本方案按"先流程、再数据、后系统、最后规则"的顺序推进，建议优先做模块一和模块二，这两块是阶段2的硬前提；模块四（经验显性化）可留到阶段2中后期再深化。

## 2. 调研对象与角色映射

按决策链五类角色锁定访谈对象，每类角色至少覆盖 1-2 人：

| 角色 | 候选岗位 | 调研重点 | 建议访谈时长 |
| :--- | :--- | :--- | :--- |
| **Sponsor / 决策者** | 奶粉事业部总经理、供应链负责人 | 项目目标对齐、资源承诺、跨部门协调授权 | 60 分钟 |
| **评估者** | 数字化中心、信息工程部、供应链计划团队负责人 | 系统现状、数据接口、既有 AI 能力覆盖边界 | 90 分钟 |
| **使用者（核心）** | 供应链计划员、分货员、补货计划员、仓储物流 | 分货补货的实际作业流程、痛点、隐性规则 | 120 分钟 × 2-3 人 |
| **影响者** | 生产计划、渠道/经销商管理、财务、物流供应商 | 上下游约束、预算口径、协同难点 | 60 分钟 |

> **提示**：使用者是本次调研的核心对象——分货/补货的隐性规则和真实痛点，只有一线计划员说得清。

## 3. 调研模块与提纲

### 3.1 模块一：分货补货现状流程还原（核心，优先做）
- **目标**：还原"工厂/基地仓 → 销售分仓 → 渠道"的补货全流程，为阶段2拆解提供 As-Is 骨架。
- **方法**：业务专家访谈 + 现场 Walkthrough（跟一个完整分货周期，从拿到销售计划到分货单下发）。

**关键问题清单**：
- **分货节奏**：分货周期是多久一次（日/周/月）？销售仓补货和基地仓补货发放是否同节奏？
- **流程起点**：一次分货从哪个动作开始？输入数据有哪些（销售计划、库存、在途、产能、促销计划）？各从哪个系统/表格来？
- **Excel 分货步骤**：请计划员逐步演示——① 打开哪些表；② 做哪些合并/汇总；③ 套用什么公式或判断；④ 哪些环节靠人工经验拍；⑤ 输出物是什么（分货单/补货单/调拨单）？
- **人工判断点**：整个流程里，哪些数字是"算出来的"、哪些是"人拍出来的"？拍板的标准是什么？
- **跨部门沟通**：一次分货要和哪些部门来回沟通几次？卡在哪里最耗时？
- **异常处理**：缺货、临期、促销突增、新仓/新渠道上线时，流程会怎么变？
- **角色分工**：谁准备数据、谁计算、谁复核、谁拍板、谁执行、谁跟踪结果？

**现场 Walkthrough 记录表**：
| 时间 | 活动 | 具体操作 | 使用工具 | 输入 | 输出 | 耗时 | 痛点标记 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | | | 🔴🟡🟠🔵 |

### 3.2 模块二：五大指标基线数据收集（量化，优先做）
- **目标**：补齐"四个提高、一个降低"的量化基线，把痛点 P0 从推断升级为实证。
- **方法**：高管访谈确认目标值 + 计划/数据团队提取基线值 + 交叉验证口径。

**数据收集表**：
| 指标 | 统计口径 | 当前基线 | 目标值 | 数据来源系统 | 负责人 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **分货效率** | 单次分货耗时/人力/频次 | | | | |
| **分仓有货率** | 现货率 / 订单满足率 | | | | |
| **库存周转率** | 周转天数 / 呆滞库存占比 | | | | |
| **商品新鲜度** | 临期占比 / 大日期库存 / 平均效期 | | | | |
| **跨仓履约率** | 跨仓履约占比 / 调拨里程 / 额外物流成本 | | | | |

**每个指标的三个追问**：
1. 这个数现在是多少？——（基线）
2. 客户希望做到多少？——（目标）
3. 这个数现在从哪个系统/表取、口径是什么？——（可获取性与口径一致性）

> **关键提醒**：五个指标是互锁的，调研时要同时拿到"同一时点"的五个数，避免口径错位导致后续方案目标函数失真。

### 3.3 模块三：系统与数据接口盘点
- **目标**：确认 APS、云商、供应链控制塔、WMS 等既有系统是否已延伸到分仓补货，判断方案是"能力移植"还是"部分新建"。

**关键问题**：
- 当前分货/补货用什么工具？是否纯 Excel？有无自建脚本/小工具？
- APS 排产结果是否回传给补货计划？接口是否打通？
- 供应链控制塔（5 大环节 15 节点）是否覆盖"分仓补货"这一环节？
- 云商系统的经销商订货数据，是否作为补货的需求输入？
- WMS 的分仓库存/效期数据，是否实时可拿到？
- 京东"一盘货"/京慧的智能补调能力，目前覆盖哪些场景？是否已延伸到奶粉分仓？

**系统盘点表**：
| 系统名称 | 功能领域 | 是否覆盖分仓补货 | API 可用性 | 数据导出方式 | 对接难点 |

| | | | | | |

### 3.4 模块四：补货规则与经验显性化（可后置）
- **目标**：把老计划员脑子里的隐性规则挖出来，为后续"推拉结合"规则引擎设计做准备。

**关键问题**：
- 分货的底层逻辑是什么？按历史销量、按销售计划、按渠道优先级、还是按仓容？
- 安全库存怎么设？分仓之间有没有差异化？谁定的？
- 促销期间分货怎么调？加量多少、提前多久备货？
- 效期/批次怎么管理？临期商品怎么处理、优先发到哪？
- 跨仓调拨的触发条件是什么？现在谁来判断"这仓缺货该从哪仓调"？

**经验规则收集表**：
| 规则 ID | 经验持有者 | 角色/年限 | 场景 | 隐性经验（原话） | 可显性化规则 | 确定性 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| | | | | | | |

---

### 3.5 模块五：前端约束与边界确认
- **目标**：明确前端承诺对后端补货的硬约束，避免方案与业务边界冲突。

**关键问题**：
- "28 天新鲜购"对补货计划的约束是什么？各分仓的效期红线是多少？
- 促销计划（如 16 亿生育补贴）如何传导到补货？当前是否脱节？
- 商品范围确认：促销品、礼盒为何排除？它们的分货逻辑是什么？
- 渠道差异：电商、母婴、KA、商超、特渠的补货需求各自有什么特殊约束？

---

### 3.6 模块六：决策链确认
- **目标**：把决策链五类角色从"推断"落到"实名"。

**待确认清单**：
- Sponsor（发起人）是谁？
- 最终决策者是谁？
- 谁评估技术可行性？
- 谁会是最终使用者（具体到岗位）？
- 有哪些外部影响者（物流供应商、集团数字化中心等）？
