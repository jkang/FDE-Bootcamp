1.1 确定公司主体

5 分钟
  • WHAT：识别客户的母公司、子公司、业务板块及所属行业地位
  • WHY：明确需求归属的组织架构，确保调研范围精准，了解企业的核心战略诉求
  • 工具：AgentOS 企业全景规划、财报库、LinkedIn、公司官网、搜索引擎

实操指南 (HOW)

活动类型：桌研
**AgentOS 衔接与操作逻辑：** 1. **输入商机信息**：在 AgentOS 中输入商机名称和已知背景（如“伊利奶粉智能分仓补货”）。 2. **调取财报与组织数据**：利用 AgentOS 自动抓取客户近三年的财报（如 10-K）或官方招股书，并提取“Segment Reporting”板块。 3. **识别核心业务与战略**：利用 AgentOS 总结其组织规模、全球分布以及最新的重大战略动作（如“AI First”战略）。 4. **输出结构化报告**：生成包含股权结构、核心业务占比、年度战略关键词的公司主体研究报告。

产出

公司主体研究报告（包含股权结构、核心业务占比、年度战略关键词）

产出示例

伊利奶粉事业部的分仓补货业务，覆盖从生产工厂、基地仓、销售分仓，到线上线下渠道客户的供应链补货链路。 整体链路可以概括为： 工厂 / 基地仓 → 销售分仓 → 电商及经销商 → 终端客户 业务涉及的上游节点包括： 8 个国内工厂 1 个 ODL 工厂 4 个基地仓 多个区域销售分仓 线上电商渠道与线下经销商渠道 其中，基地仓包括天津基地仓、呼市基地仓、杜蒙基地仓、武汉基地仓等；销售分仓包括合肥、天津、广州、郑州、成都、武汉、呼市、济南、柳州等销售仓。 组织边界 组织范围：伊利奶粉事业部 业务范围：伊利奶粉事业部所属生产工厂到各分仓的补货业务 商品范围：伊利奶粉事业部经营的所有在售商品，不包含促销品及礼盒 覆盖供应链网络节点：工厂仓、区域分仓 渠道范围：线上电商、线下经销商 业务本质和目标 未来需要建立一套面向奶粉事业部的分仓补货计划机制，使生产、物流、销售分仓和渠道需求之间形成更高效、更准确、更可控的协同关系。奶粉业务具有较强的供应链复杂性： 渠道多，包括线上电商、KA 客户、经销商、母婴、商超、特渠等 仓网多，包括工厂仓、基地仓、区域分仓 商品对日期和新鲜度敏感 区域需求波动明显 缺货会影响订单满足和客户体验 库存过高会影响周转和新鲜度 因此，分仓补货计划既要解决“货够不够”的问题，也要解决“货在哪里、是否新鲜、是否在正确的仓、能否及时满足订单”的问题。

实践提示

重点关注财报中提到的“Risk Factors”。如果提到“人力成本上升”或“交付效率瓶颈”，这就是 AI 介入的绝佳切入点。不要只看官网的 PR 稿，财报里的风险警示往往才是业务负责人的真实痛点。

1.2 企业画像

5 分钟
  • WHAT：建立对客户企业的全方位认知，包含企业基座、组织规模、业务组合、数字化成熟度、战略痛点及决策链
  • WHY：将模糊的商机背景具象化，识别业务增长引擎与数字化 Gap，为后续场景拆解提供战略依据
  • 工具：AgentOS 企业画像 Agent、财报库、行业研报、LinkedIn

实操指南 (HOW)

活动类型：桌研
**AgentOS 衔接与操作逻辑：** 1. **输入商机信息**：在 AgentOS 中输入商机名称和已知背景（如“伊利奶粉智能分仓补货”）。 2. **自动化调研**：利用 AgentOS 自动化执行企业全景扫描，抓取近三年财报、行业地位、数字化底座分布及战略风险因子。 3. **识别核心增长与 Gap**：AgentOS 会自动提取关键经营数据（如奶粉营收占比、毛利等）并与公开的数字化动作（如 APS、一盘货等）进行比对，识别数字化空白点。 4. **生成初稿**：输出一份包含企业基座、组织规模、业务组合、数字化现状及战略痛点的企业认知报告，作为后续现场调研的“50%-ready”底稿。

企业业务价值流分析方法论

1. WHAT｜什么是价值流分析

定义：围绕特定利益相关者，从业务触发开始，经由多个价值创造阶段，最终形成业务价值结果的端到端路径。

核心概念

概念 含义
Stakeholder为谁创造价值
Trigger什么触发价值流
Value Proposition最终创造什么价值
Value Stream完整的端到端价值创造
Value Stream Stage价值创造中的关键阶段
Outcome / Value Item阶段性/最终产生的价值结果
Capability支撑价值创造的业务能力
Process具体执行方式
KPI衡量价值创造效果
Stakeholder → Trigger → Value Stream → Value Stream Stage → Outcome
                    ↓
                Capability / Process / KPI

示例：需求与供应计划

需求识别 → 需求预测 → 供给配置 → 库存平衡 → 计划确认

最终实现：将市场需求转化为可执行的供需决策，实现需求满足与库存效率的平衡。

2. WHY｜为什么做价值流分析

  • 看价值：从部门/流程视角转向端到端价值视角
  • 找断点：识别价值创造中的阻塞、浪费和损失
  • 建架构：连接战略、价值流、能力、流程和 IT
  • 促转型：找到业务优化、数字化和 AI 的价值机会
核心目的：不是把流程画全，而是看清“价值如何产生、在哪里损失、如何提升”。

3. HOW｜如何开展价值流分析

① 明确范围：业务领域、价值对象、核心 Stakeholder
↓
② 识别价值流：从经营目标出发识别企业核心端到端价值流
↓
③ 定义价值流：明确 Trigger、Value Proposition、Outcome
↓
④ 拆解 Stage：识别 4–7 个关键价值创造阶段
↓
⑤ 建立映射：Value Stream / Stage → Capability → Process → System
↓
⑥ 识别优化机会：价值损失 → 能力差距 → 数字化 / AI 机会 → KPI

4. 判断标准（六看）

判断维度 核心问题
看价值是否明确创造什么业务价值？
看边界Trigger 和 Outcome 是否清晰？
看端到端是否形成完整价值闭环？
看 Stage是否体现价值递进，而非简单流程步骤？
看粒度同层级价值流是否保持一致粒度？
看结果是否能够关联经营结果和 KPI？
好的价值流分析 = 价值清晰 + 边界合理 + 端到端 + 阶段递进 + 粒度一致 + 可衡量

⚠️ 警惕：把部门、流程、系统或具体操作直接当成 Value Stream

**1. 共创 Agenda** - 第一部分（10min）：回顾已确认的业务蓝图与 KPI。 - 第二部分（30min）：填写 AI Opportunity Canvas。 - 第三部分（20min）：推演成功度指标 (MoS)。 **2. 共创准备** - 打印或准备在线白板的“AI 机会画布 (AI Opportunity Canvas)”。 - 邀请业务负责人、一线操作人员与客户 IT 代表共同参与。 **3. 共创过程 Facilitate** - **引导填写画布**：引导客户共同定义五个核心要素：输入数据（用户提供什么）、模型任务（AI 做什么）、输出格式（结构化 JSON 还是 Word）、用户交互（界面在哪里）以及业务价值。 - **推演技术指标**：将业务 KPI 转化为技术维度的“成功度指标 (MoS)”，如 AI 生成内容的采纳率 (Acceptance Rate)、幻觉率容忍度等。 **4. 如何得出共创结论** - FDE 现场梳理并总结画布内容，确保逻辑自洽（如：输入数据能否支撑模型任务的实现？）。 - 最终产出由客户签字确认的场景需求规格说明书 (SRP)，作为后续研发的“作战手册”。

# 分仓智能补货 · 场景定义画布 (SRP) **1 场景基础信息** - **名称**：分仓智能补货 - **面向角色**：物流计划、调度组 - **痛点锚定**：多仓×多SKU×多约束（库存/在途/待检/效期）人工 Excel 无法全局最优。 **2 AI 机会定义** - **AI 任务**：多约束库存分配优化 (OR/运筹优化)。 - **AI 角色**：物流计划员的智能调度助手。 - **业务价值**：提升分货效率、有货率、周转率与新鲜度。 **3 成功度指标 (MoS)** - **可用率**：AI 生成的分货建议初稿采纳率 > 80%。 - **准确度**：模型预测补货量与实际发货量的偏离度 < 10%。 - **提效**：分货计划编制时间缩减 60% 以上。 **4 关联系统与数据** - **系统**：APS、云商、WMS。 - **数据**：待检/合格/在途库存、历史销量、促销计划、效期批次。

实践提示

MoS 指标要尽量客观。与其问用户“你觉得 AI 写得好吗”，不如统计“用户在 AI 生成的内容上修改了多少个字符”。用客观的行为指标来衡量 AI 的表现。

1. 全流程回顾

  • 理需求三部曲：懂业务 (客户研究) -> 找痛点 (场景发现) -> 定方案 (场景定义)
  • 核心价值：通过“理需求”将模糊的客户诉求转化为结构化的 AI 场景规划 (SRP)，为后续交付打好地基

2. AgentOS 实操演示 (关键环节展示)

  • 桌研提效演示 (Desk Research)
    • 演示如何使用 AgentOS 聚合搜索 Ascentium 及伊利奶粉所在的行业报告，并在 30 秒内提取出核心价值流模型
    • 展示如何通过 AgentOS 对 20 份历史访谈录音或业务痛点记录进行语义聚类，自动生成包含“痛点频率”的热力图（如伊利的“跨仓履约”痛点）
  • 共创产出演示 (Co-creation)
    • 演示如何使用 AgentOS 辅助生成初版“场景画布”：输入痛点清单，AI 自动推荐 RAG + Agent 或大模型智能补货调度的架构组合

3. 核心精神总结

  • 以业务价值为导向：所有的 AI 场景必须最终关联到客户的战略 KPI
  • Start with 50%-ready：善用 AgentOS 提效，永远带着“假设”去共创
  • 可视 = 价值：用原型 and Demo 锁定客户预期，减少交付偏差
